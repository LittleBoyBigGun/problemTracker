模板配置说明 ✕

一、三个表（TOML）

[record] 主页列表与历史页的显示格式
[copy] 点「复制」时导出的文本格式
[settings] 设置项，目前支持时间格式

二、键名

template 模板内容（record / copy 表内）
time_format 时间格式（settings 表内）

三、可用变量

#开始时间 记录开始时间（已含提前偏移）
#结束时间 记录结束时间（已含延后偏移）
#账号全称 如「布拉格のAAA」
#账号简称 全称去掉「账号前缀」后的部分
#日期 记录所属日期，如 2026-09-28
#故障原因 当前选择的故障原因

四、时间格式

支持 yyyy 年、mm 月（首次出现）／分（之后出现）、dd 日、hh 时、ss 秒： time_format = "hh:mm:ss" time_format = "yyyy-mm-dd hh:mm:ss"

五、完整示例

# 记录项：主页列表与历史页的显示格式 [record] template = "#账号简称 #开始时间 到 #结束时间 #故障原因" # 复制项：点「复制」时导出的文本格式 [copy] template = "#账号全称 #日期 #开始时间 到 #结束时间 （#故障原因）" # 设置项：时间显示格式 [settings] time_format = "hh:mm:ss"

六、注意

模板含 # 变量，因此值必须用引号包裹，否则会被当作注释截断； 以 # 开头的行为注释。两个账号的模板相互独立，需分别配置；留空则回落到默认模板。
